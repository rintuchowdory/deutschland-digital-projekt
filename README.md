# Projekt: Deutschland wird digital abgehängt?

## Leitfrage
Warum hinkt Deutschland bei Digitalisierung und KI hinter einigen anderen Ländern her?

## Teilbereiche
- **Staat & Behörden**: Digitale Bürgerdienste, Online-Anträge, Bürokratie
- **Bildung**: Digitale Schulen, IT-Ausstattung, Programmierunterricht
- **Unternehmen**: Cloud-Nutzung, KI-Einsatz, Automatisierung
- **Infrastruktur**: Glasfaser, 5G, Rechenzentren

## Datenquellen

- [Bundesnetzagentur](https://www.bundesnetzagentur.de)
